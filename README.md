# McNeil Maseko Portfolio

A responsive personal portfolio website built with React, TypeScript, and Vite.

## How to Run

### Prerequisites

- Node.js 18 or newer
- npm

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

### Create a production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Run linting

```bash
npm run lint
```

## Languages Used

- **TypeScript**: Application logic, React components, and configuration.
- **TSX**: React components with TypeScript and JSX markup.
- **CSS**: Global styles, animations, responsive design, and custom theme styles.
- **HTML**: The main document shell in `index.html`.
- **JavaScript**: Build and tooling configuration used by the Node.js ecosystem.

## Main Technologies

- React
- Vite
- Tailwind CSS
- shadcn/ui and Radix UI
- Lucide React icons
- React Router
- EmailJS for the contact form
